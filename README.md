# Learnova

Learnova is a full-stack learning platform designed to connect **students, teachers, and administrators** in one integrated educational environment.

Teachers can create and manage courses, publish learning materials, create assignments and exams, and interact with students. Students can enroll in courses, access learning materials, submit assignments, take exams, track their progress, and communicate with other users. Administrators can manage users, courses, and the overall platform.

---

## Features

* Student, Teacher, and Admin accounts
* Role-based access control
* Course creation and enrollment
* Learning materials and notes
* Course announcements
* Course discussions
* Assignments and submissions
* Assignment grading
* Timed examinations
* Student progress tracking
* User profiles
* Friend requests
* Private messaging
* Notifications
* Real-time communication
* PostgreSQL database
* JWT authentication
* Password hashing with bcrypt
* Real-time features with Socket.io

# Run Locally

## Requirements

* Node.js
* npm
* PostgreSQL

## 1. Configure the Database

Create a PostgreSQL database, then create:

```text
backend/.env
```

Add:

```env
DATABASE_URL=postgres://YOUR_USER:YOUR_PASSWORD@localhost:5432/YOUR_DATABASE
JWT_SECRET=replace-this-with-a-long-random-secret
PORT=5000
```

For a **new, empty database only**, create the tables and sample data with:

```bash
psql "YOUR_DATABASE_URL" -f database/schema.sql
```

> **Warning:** `database/schema.sql` drops and recreates the `public` schema. Do not run it on a database containing data you need. For an existing Learnova database, back it up and use the appropriate SQL migration from `database/migrations/`.

## 2. Install Dependencies

From the project folder:

```bash
cd backend
npm install
```

## 3. Start the Application

Development mode:

```bash
npm run dev
```

Or start without the development watcher:

```bash
npm start
```

Open:

```text
http://localhost:5000
```
